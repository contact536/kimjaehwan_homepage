# Typography
Pretendard v1.3.9, distributed with its SIL OFL license in public/fonts.
Official source: https://github.com/orioncactus/pretendard/tree/v1.3.9
Compared SUIT (https://github.com/sun-typeface/SUIT) and Noto Sans CJK (https://github.com/notofonts/noto-cjk).
Selected Pretendard for consistent Korean/Latin UI and variable weights. Self-hosted WOFF2, font-display:swap with system fallback.
Headings use 600–650 weight; long-form text 16–17px and 1.85 line height. Narrow screens preserve 16px body and inputs. Monospaced code is unchanged.
Apply with scripts/apply-typography.mjs, last in content:generate.
