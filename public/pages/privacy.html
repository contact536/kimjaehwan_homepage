방문 통계 안내

이 사이트는 공개 페이지의 이용 현황을 자체 서버에서 집계합니다. 관리자 화면에서 일별·월별 페이지 조회, 하루 단위 방문자 수의 합계, 인기 페이지, 유입 사이트와 접속 국가·대략적인 시·도/주를 확인할 수 있습니다.

집계 방식

방문자의 브라우저에 하루 동안 유효한 무작위 쿠키를 설정합니다. 운영 데이터베이스는 해당 날짜의 중복 방문 판정에만 쓰는 해시를 만들며 날짜가 지나면 해시를 삭제합니다. 백업 사본은 별도의 백업 보관기간에 따라 관리합니다. 공개 페이지 조회수와 첫 방문 유입 사이트·국가 코드·가장 넓은 행정구역 이름별 일별 방문자 합계는 기간 제한 없이 누적합니다. 접속 IP는 국가와 대략적인 행정구역을 판정할 때만 사용하며 방문 통계 데이터베이스에 저장하지 않습니다. 도시명·좌표·브라우저 정보도 저장하지 않습니다. 유입 URL의 경로나 검색어는 저장하지 않고 사이트 이름만 집계합니다.

관리자 방문과 일반적인 자동화 방문은 통계에서 제외합니다. 누적 통계는 운영자가 삭제할 때까지 보관하며 방문 기록으로 개인의 이름이나 신원을 확인할 수 없습니다. 쿠키를 지우거나 브라우저를 바꾸면 같은 날에도 새 방문자로 집계될 수 있습니다.

위치 데이터

접속 국가와 시·도/주는 대략적인 IP 위치 데이터로 판정합니다. VPN·이동통신·회사망 때문에 실제 방문 위치와 다를 수 있습니다. IP 위치 데이터 파일은 매월 갱신하지만 과거 방문의 판정 결과는 소급 변경하지 않습니다. 지역 통계는 기능 적용 이후 방문부터 저장하며, 판정되지 않는 경우 ‘알 수 없음’으로 표시합니다. IP Geolocation by DB-IP
