KorTaxArena — LLM 생성 프로그램 · 테스트 선택

XAIKOREA · 연구 진행 중

연구 상세/연구 원고 · 첫 페이지

LLM 생성 프로그램의 추가 테스트 구성 방식과 정답 판정 기준이 오류 발견에 미치는 영향을 연구합니다.

KorTaxArena 상세 설명

LLM 생성 프로그램의 테스트 선택과 오류 발견을 다루는 탐색 연구입니다. 최신 영문 개정 49안은 18개 합성 산술 과제와 6개 모델 구성의 생성 시도 540건을 바탕으로 추가 테스트 구성 방식과 정답 판정 기준을 비교합니다. 연구 중인 원고의 첫 페이지를 논문·자료 페이지에서 소개합니다.
