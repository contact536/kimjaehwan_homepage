편집 순서

  1. 콘텐츠 종류를 선택하고 이름으로 항목을 찾습니다.
  2. 항목을 선택해 필드를 수정한 뒤 변경사항 저장을 누릅니다. 자동 저장은 제공하지 않습니다.
  3. 저장 완료 메시지를 확인하고 표시 페이지 보기를 열어 결과를 확인합니다. 이미 열려 있다면 새로고침하세요.

다른 항목이나 페이지로 이동하기 전에 저장하세요. 입력 중인 내용은 별도로 보관되지 않습니다.

저장과 반영 범위

연구 본문
기존 3개 연구의 제목·부제·요약·본문을 수정합니다. 공개 연구 화면과 연구 도우미가 저장한 내용을 사용합니다. 신규 연구 생성과 삭제는 지원하지 않습니다.
학회 · 저널
각 탐색 페이지의 목록과 필터 정보에 반영됩니다.
연구 소식
홈의 Journey에 반영됩니다. CV의 기업 주요 이력은 별도 자료로 관리합니다.
프로필
이름·직함·연구 소개·이메일은 홈에 반영됩니다. 하위 페이지 프로필은 별도 자료로 생성되며 수치 필드는 현재 화면에 표시되지 않습니다.

콘텐츠 저장과 사이트 배포는 별개입니다. 저장은 현재 접속한 사이트의 데이터에 적용됩니다. 로컬에서 저장한 데이터나 수정한 디자인이 배포 사이트로 자동 전송되지는 않습니다.

문제 해결

다른 곳에서 수정되었다는 오류
작성 중인 내용을 따로 복사해 둔 뒤, 컬렉션과 항목을 다시 선택해 최신 내용을 불러오세요. 변경 사항을 비교한 후 저장합니다.
로그인이 다시 필요한 경우
관리자 비밀번호로 다시 로그인하세요. 저장 성공 메시지가 없었다면 표시 페이지에서 반영 여부를 확인하세요.
수정 전 내용을 보관하려면
상단의 데이터 내보내기로 현재 저장된 데이터를 다운로드할 수 있습니다. 내보내기는 자동 복원 기능이 아닙니다.
